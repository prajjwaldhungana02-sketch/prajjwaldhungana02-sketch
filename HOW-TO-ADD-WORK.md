# How new work lands on the GitHub profile

1. **New research project**: create a repo named `topic-place-method` (e.g. `nepal-hydro-jobs-eo`), copy `templates/PROJECT_README_TEMPLATE.md` as its README, then add one row to "Research projects" in the profile README.
2. **New paper**: add it under Papers (published / under review / working paper). Link the PDF or DOI, and the repo if there is one.
3. **REAR Econ post**: goes in `rear_econ_posts` under `aemm/` or `teed/` by week, as now. The profile links the folders, so no edit is needed per post.
4. **Code or tool**: add a row to "Code and tools".
5. **Private work** (ICIMOD, client data): keep the repo private; list it on the profile only with an OK from the data owner.

Pin up to 6 repos on the profile: the two signature projects first, then REAR Econ, then the best paper repos.
